# DnD
Dungeons &amp; Dragons stuff to make life easier

# About
One tool so far has been made to make life easier.
It generates maps programmatically.

The idea that sparked this repo is DnD-BuildingFloorPlans.py -- Basically, I wanted to build a tool to generate floor plans for ttrpgs and do it in the form of an app you can click on like a rat clicking for food pellets, and it makes map after map, as fast as you can click (maybe not literally but it is supposed to be fast and satisfying to click and use).

Hideout generator is how I named the first iteration but then renamed for version 2.0.

The latest name for the tool is DnD-BuildingFloorPlans and the entire reason this was all rewritten for 2.0 is to make these maps usable if someone prints them on a full sheet of paper. You could use these maps a lot of different ways but what 2.0 is doing is making sure the files generated can be printed at home by a person with a printer and actually play with what comes out of your printer. Other compatibility features include a 70 pixel grid, but these files have not been tested for compatibility with any online platforms. You get .jpeg files when you hit save. I hope you enjoy.
