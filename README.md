Dungeons &amp; Dragons stuff to make life easier

# About
One tool so far has been made to make life easier.
It generates maps programmatically.

The idea that sparked this repo is DnD-BuildingFloorPlans.py -- Basically, I wanted to build a tool to generate floor plans for ttrpgs and do it in the form of an app you can click on like a rat clicking for food pellets, and it makes map after map, as fast as you can click (maybe not literally but it is supposed to be fast and satisfying to click and use).

Hideout generator is how I named the first iteration but then renamed for version 2.0. I can read a Python script but I only speak English and PowerShell. Readme.txt or .md files will be published with the scripts. AI is generating, editing and/or reviewing the code. If you don't see a readme file for a script, it is on the way.

The latest name for the tool is DnD-BuildingFloorPlans and the entire reason this was all renamed and all the code rewritten and redesigned is to make these maps usable if someone prints them on a full sheet of paper. You could use these maps a lot of different ways but what 2.0 is doing is making sure the files generated can be printed at home by a person with a printer and actually play with what comes out of your printer. Other compatibility features include a 70 pixel grid, but these files have not been tested for compatibility with any online platforms. You get .jpeg files when you hit save. I plan to keep working on hideout generator as well, it makes much larger maps if you just count the grid squares (designed to represent 5'x5'). The code for that iteration is the last file in this repo. The latest version of this project is the first file, and the second file is the accompanying readme.

I hope you enjoy.
